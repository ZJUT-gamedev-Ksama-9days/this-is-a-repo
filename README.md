# 重力方框物理原型

## 环境与运行

- Unity **6000.3.27f1**。
- 工程根目录：当前目录。
- 打开 `Assets/GravityPrototype/Scenes/PhysicsSandbox.unity`，点击 Play。
- **A/D 或左右方向键**移动，**空格/W/上方向键**跳跃；保留自然身体碰撞，但持续身体推挤非常微弱（上限 **0.5 N**），搬运物体请用机械臂。
- **Q / E** 上一个/下一个装置；**1 / 2 / 3**（含小键盘）分别选择重力装置、机械臂、空手，**不再换球**。
- 手持重力装置时，鼠标左键按住青色方框内部拖动。机械臂模式下，瞄准物体并按住**左键抓取**、**右键持续推动**；松左键放开抓取。**R** 保留当前球种，恢复玩家满血、全体位置并重新装备重力装置。
- 也可以通过 `Tools > Gravity Prototype > Open or Create Physics Sandbox` 打开场景。已有场景不会被生成器覆盖。
- 已有试验场若缺少生命组件，可在 Edit Mode 执行 `Tools > Gravity Prototype > Add Health to Current Player` 并保存；新生成的玩家会自动带上生命、摔落伤害与血条。
- 原型使用内置渲染管线和 Unity 旧版 `Input` API；不依赖新 Input System、URP 或美术包。

## 宇航员装置

- 默认装备重力装置；只有手持它时可以拖框。切到机械臂或空手会立即停止拖动，方框停在原位。
- 从收起重力装置开始计时：**0–1.5 秒保持完整效果，1.5–3 秒线性淡出，3 秒完全消失**。期间从机械臂切到空手不会重置计时；重新拿出重力装置会立即恢复原位方框和完整效果。
- 淡出同步降低边框/填色/箭头透明度与物理影响：`g当前 = Lerp(g背景, g框内, 影响权重)`。不是仅隐藏画面、也不是失重后一直悬浮；完全消散后恢复背景重力。反向等强重力淡出一半时会短暂经过净重力为零。
- 机械臂有效距离默认 **2.5 m**，只作用于视线内可模拟的动态刚体，不隔墙抓取/推动，也不能抓自己或其他玩家。左键选中接触点后用限力弹簧跟随鼠标，保留重力、碰撞和转动，不瞬移物体；弹簧采用隐式步进并计入抓取点转动响应，避免轻气球数值发散。推力默认 **55 N**，抓取最大力 **90 N**，并给玩家施加等大反向力。
- 机械臂抓取/拖动只允许目标刚体质心处于当前场景的有效重力框内；拖动过程中目标离开重力框或因场强消散而不再受局部重力时会自动释放。右键推动仍可作用于范围内、视线内的可动物体。
- **玩家未使用机械臂时**，身体持续推挤的驱动力上限为 **0.5 N**，仅产生非常微弱的推挤；保留玩家与球体的真实碰撞、踩球和头部砸击。

- 青色手持方块、黄色臂状方块和连线是占位表现，不是正式机械臂动画。当前场景使用 Player 实例新增组件，未覆盖旧 `Player.prefab`；新生成的试验场自动接入。已有试验场可执行 `Tools > Gravity Prototype > Add Astronaut Devices to Sandbox` 后保存。

## 当前物理规则

- 使用 Unity `Rigidbody2D` / `Collider2D` 处理碰撞、接触、摩擦和物理积分；没有重新实现碰撞引擎。
- **主角和小球都受重力框影响**。主角进入框内后按区域方向加速，离开后恢复世界重力；角色朝向、支撑面判定和跳跃方向跟随当前重力，使用连续碰撞检测。
- 角色沿垂直于重力的行走方向以受限驱动力加减速，通过真实接触推球，不会直接改写小球速度；支持斜坡行走、短暂离地容错与跳跃输入缓冲，不支持二段跳。竖直重力下 A/D 始终对应画面左/右，侧向重力下 A/D 沿墙面下/上移动。
- 主角或小球的**世界空间质心**进入方框时使用局部重力；仅碰撞体边缘碰到框不算进入，边界点算框内。
- 约定 **1 Unity 世界单位 = 1 米**。按已确认的太空场景规则，保留地球式空气环境，背景重力为 `(0, -9.81×0.7)`，即 **6.867 m/s²（地球的 70%）**；这不是舱外真空失重。
- 初始方框为 `4 × 4` 米，框内重力朝上、强度同为 **6.867 m/s²**。它是同强度的重力反转，不是额外叠加一个 18 m/s² 的升力。
- 方框不带实体碰撞边框，不推挤或夹住物体。
- 进出方框不直接改写速度；离开框后保留动量并恢复世界重力。
- 重力按 `F = m g` 换算为力，忽略空气时木球、铁球具有相同的升降加速度；不能通过人为降低铁球加速度体现“重”。空气中小差异由明确的排空气体积、质量和阻力公式产生。
- 本场景三种球和玩家都使用 `gravityScale = 1`，不再靠 0.25 或 2.4 倍重力制造缓落/加速；原型倍率字段仅保留作旧数据兼容。
- 只有带 `GravityBody2D` 的动态刚体参与局部重力；未挂此组件的物体不受影响。
- 每个物理步重新判断区域，不依赖移动 Trigger 的进入/离开回调。框移到休眠刚体上或离开时会将其唤醒。
- 若将来放置多个区域，优先级高的生效；相同优先级则后启用的生效，重力不叠加。
- 区域判定以物理步为准：若一个框在两次物理步之间完全扫过并离开小球，不额外施加瞬时冲量。

## 三种球与接触摩擦

试验场保留一个 `Ball` 实例，默认木球。运行时不再用数字键换球；可在 Edit Mode 修改 `BallMaterial2D.profile` 并执行 `Apply Material Profile`，或用三种独立 Prefab 放置不同球。测试/调试仍可调用 `PhysicsSandboxController.SelectBallType`，不会给玩家回血；已有 `Ball.prefab` 没有被覆盖。

| 球种 | 结构参考值 | 计算总质量 kg | 摩擦系数 | 弹性系数 |
| --- | --- | ---: | ---: | ---: |
| 气球 Balloon | 空气填充，外皮含结 15 g | 0.3952 | 0.8 | 0.5 |
| 木球 Wood | 600 kg/m³ 木壳，厚 2 mm，内含空气 | 3.0222 | 0.35 | 0.12 |
| 铁球 Iron | 7850 kg/m³ 铁壳，厚 0.3 mm，内含空气 | 5.5960 | 0.15 | 0.03 |

三者外径均为 **0.84 m**，空气密度参考 **1.225 kg/m³**，常数球体阻力系数参考 **0.47**。这些是为当前原型选取的可调参考值，**不是所用道具的实测数据**；摩擦和弹性仍是调试参数，材料名称本身不足以决定接触系数。

- 气球为粉色、轻、弹性较高，充普通空气而不是氦气。缓落来自浮力抵消大部分重量及空气阻力，**不再使用减重力倍率/任意线性阻尼**。木球和铁球都是可移动的空心壳，不是先前误假设的实心巨球。
- 摩擦系数由三份真正的 `PhysicsMaterial2D` 提供，不是用阻尼代替摩擦。接触效果同时取决于另一碰撞面的材质。**滑动摩擦和滚动阻力不是一回事**：自由滚动时，高摩擦可以帮助球形成滚动，不能简单理解为“高摩擦一定更快停”。参考受力模型下线性/角阻尼均为 0，空气阻力另按公式施力；未额外模拟滚动阻力。
- 配置位于 `Assets/GravityPrototype/Physics/Balloon.asset`、`Wood.asset`、`Iron.asset`。对应接触材质为同目录 `BalloonContact.physicsMaterial2D`、`WoodContact.physicsMaterial2D`、`IronContact.physicsMaterial2D`。
- 三个 Prefab 位于 `Assets/GravityPrototype/Prefabs/BalloonBall.prefab`、`WoodBall.prefab`、`IronBall.prefab`，都已挂载局部重力、材质配置和砸击伤害组件；有颜色和简单细节区别，没有正式美术。
- `BallMaterial2D` 在出生或显式切换时应用计算质量、球壳转动惯量、碰撞半径、材质和颜色。默认 `Use Reference Physics` 开启，此时旧的质量/重力倍率/阻尼字段不参与计算。配置改动后可重启 Play Mode 或执行组件菜单 `Apply Material Profile`；球的 Transform 要保持均匀缩放。
- 调试 API 选择球种只复位受控小球及其速度，并释放机械臂，**不重置玩家 HP 和砸击冷却**。R 恢复玩家满血、方框和受控小球位置，保留所选球种并重新装备重力装置；额外手工摆放的球不自动纳入当前试验场单球重置流程。
- 新生成的试验场自动包含三种配置。已有试验场可在 Edit Mode 执行 `Tools > Gravity Prototype > Add Three Ball Materials to Sandbox` 并保存。生成器保留已存在配置、材质和 Prefab 的调参，不覆盖已有资产。

## 受力公式与模型边界

设外半径 `R = 0.42 m`、壳厚 `t`、内半径 `r = R-t`：

- 排空气体积：`V = 4πR³/3`；迎风面积：`A = πR²`。
- 木/铁球总质量：`m = ρ壳 × 4π(R³-r³)/3 + ρ内部空气 × 4πr³/3`。
- 球壳转动惯量：`I壳 = (2/5)m壳(R⁵-r⁵)/(R³-r³)`；内部气体近似均匀随动球体，`I气 = (2/5)m气r²`。
- 气球质量：`m = ρ内部空气 × V + m外皮`；外皮用薄球壳惯量 `2m外皮R²/3`。
- 重力：`F重 = m g当前场`；浮力：`F浮 = -ρ环境空气 × V × g当前场`。
- 静止空气中的阻力：`F阻 = -(1/2)ρ环境空气 Cd A |v|v`。
- 净力交给 Unity `Rigidbody2D.AddForce(..., Force)` 积分，`a = ΣF/m`；没有自定义位移动画、抬升速度上限或“重球减速倍率”。框内用重力差值替换世界重力，避免两份重力相加。

忽略空气、从静止起步，反重力作用 **0.5 s** 后应达到约 **3.4335 m/s**，连续理论位移约 **0.8584 m**。Unity 的 `0.02 s` 半隐式欧拉积分得到约 **0.8927 m**，这是离散步长误差，不是场强翻倍。空气模型下木球和铁球因浮力/阻力不同产生小幅差异，不保证完全等速。

模型边界：

- 仍是 **Unity 2D 刚体接触求解**，用三维球壳的质量/惯量及空气受力作平面运动近似，不是完整 3D 流体或结构仿真。
- 局部重力反转本身是游戏机制。这里假定球周围空气的等效浮力随本地重力立即调整，不模拟气压传播、对流、湍流、风或跨区域空气流动。
- 常数 `Cd=0.47` 只作参考近似，不覆盖所有雷诺数；气球不模拟外皮变形、泄气、内部压力、破裂。空心木/铁壳不模拟屈曲与焊缝。
- 玩家质量设为 **70 kg**，重力倍率为 1；环境保持 **70% 地球重力（6.867 m/s²）**，起跳速度调整为 **4.6 m/s**，理论跳高约 **1.541 米**、同高度往返滞空约 **1.340 秒**（`h=v²/(2g)`，忽略离散积分误差）。只增加主动起跳速度，不降低重力、不改球的受力，也不在空中持续向上推。角色移动仍为游戏控制器，包含输入、支撑检测、受限驱动力和短暂离地容错，不是人体动力学模型。
- 地面/墙体改用 `Physics/GroundContact.physicsMaterial2D`，摩擦 0.35、弹性 0，避免把旧球的 0.12 弹性赋给地面，导致低重力角色反复弹离；球自身弹性保持独立。
- 生命值、摔落扣血和接触力到 HP 的映射仍是游戏规则，不声称是现实伤害医学模型。低重力下从相同高度落下更慢，碰撞冲量及接触力也会相应变化。
- 低重力下高速撞到斜坡尖角可能被接触冲量抬离地面；控制器不通过瞬移或强制吸附掩盖这个现象。坡面沿切线驱动、2 cm 支撑检测仅用于判断是否可跳跃，不改变球的运动或把离地角色拉回地面。

## 玩家生命与摔落伤害

- 玩家默认最大生命 **100**，右上角显示血条、当前/最大生命值；受伤短暂闪白并显示本次落差和伤害。
- 沿**当前重力方向**计量本次腾空的落差，不是绝对世界 Y 高度，也不是单看撞击速度。向上重力撞到天花板、侧向重力落到墙面同样结算；重力方向切换时开始新的落差段，失重时不累计落差，避免旧方向高度误扣血。
- 默认安全落差 **3 米**（包含阈值），超出部分每米造成 **20 点**伤害：`伤害 = max(0, 落差 - 安全落差) × 每米伤害`。
- 例如 3 米不扣血、4 米约扣 20、6 米约扣 60、8 米约扣 100；数值受实际接触位置和离散物理采样影响。正常跳跃约 1.5 米，不会扣血。
- 每段腾空在落到当前重力的支撑面时结算一次；持续接触不会重复扣血，不朝向支撑方向的墙壁不当作落地，落地立即按跳跃也不能跳过伤害。最近一次伤害和对应落差会保留显示，不被后续无伤接触抖动清空。
- 血量归零后禁止角色移动和跳跃，显示 `DEAD - Press R to restart`；不会自动回血或自动复活。按 **R** 复原全体并满血，清除旧落差和跳跃输入。
- 当前已有场景采用玩家实例上的新增组件；没有把场景实例改动应用回旧的 `Player.prefab`。生成器之后新建的玩家会自带这些组件。

## 小球砸击伤害

- **只在小球砸中人物头部时扣砸击伤害**，身体、脚部、高速侧擦及玩家踩球均不造成球砸击伤害；独立的摔落伤害规则不变。
- 头部区域为胶囊体沿人物当前重力反方向的顶部 **35%** 高度，随重力翻转而旋转；接触位置必须在该区域，且球从头顶方向主动撞入。普通身体碰撞仍保留真实推挤、滚动、弹跳，但不扣 HP。
- 只累加符合头部区域与入射方向条件的 `ContactPoint2D.normalImpulse`，得到 `J`（N·s）；不使用旋转表面速度充当球的入射速度，角色跳头顶向静止球也不算球砸头。
- **伤害门槛直接看头部接触冲量**：默认 `J ≤ 5 N·s`（含阈值）免伤；超过后按真正的指数函数而非平方/幂函数递增。
- 默认公式：`D = min(100, 5 × (2^((J - 5)/10) - 1))`，只在 `J > 5 N·s` 时使用。可调参数为安全冲量 `J₀`、指数翻倍冲量间隔 `ΔJ`、伤害系数 `S`：`D = min(Dmax, S × (2^((J-J₀)/ΔJ)-1))`。
- 示例：`J = 5 / 15 / 25 / 35 / 45 / 55 N·s` 分别扣 `0 / 5 / 15 / 35 / 75 / 100 HP`；同样增加 10 N·s，未触顶前伤害增量会翻倍。阈值处连续，没有刚超过阈值就固定扣一大截血的跳变。
- 平均接触力仍按可调等效缓冲时长 `T = 0.10 s` 显示为 `F平均 = J / T`（N），**仅作反馈，不决定伤害阈值或伤害值**。改变 T 不改变同一冲量的指数伤害；这也不是实测峰值力。代码会在指数运算前检查伤害上限，避免极端冲量造成数值溢出。
- **不会把算出的力再次 AddForce 到玩家身上**：求解器已施加碰撞冲量，再施加会重复计算动量。平均力仅用于伤害计算和 HUD 显示，不是峰值撞击力。
- 小球的碰前线速度只用于确认它主动朝头部撞来，不作额外伤害倍率；球体自转不会直接变成头部冲量伤害。足够小的冲量因安全冲量阈值而免伤，不能假设所有低速重球砸头都安全。
- 只在新接触时结算，不在持续接触中每帧扣血；同一玩家的小球砸击有 **0.4 秒**冷却，接触抖动、同时多个小球不会连扣。冷却不屏蔽独立的摔落伤害。当前不模拟持续挤压伤害。
- 仅在头部受伤或摔落伤害后显示对应扣血反馈，不在 HUD 暴露冲量或平均力等诊断数值。
- 安全冲量、指数间隔、伤害系数和上限是可调的游戏规则，T 是等效缓冲参数。刚体接触没有材料形变、接触面积或宇航服缓冲数据，不用指数 HP 映射声称真实人体伤害。
- 当前在场景 `Ball` 实例上新增伤害组件，旧 `Ball.prefab` 没有被覆盖；新生成的试验场会自动带上砸击组件。自行放置旧球 Prefab 时需添加 `BallImpactDamage2D`。

## 调参入口

选中场景的 `Gravity Frame`，调整 `GravityRegion2D`：

- `Size`：方框大小。
- `Direction`：世界空间方向，例如 `(0, 1)` 朝上、`(1, 0)` 朝右、`(0, 0)` 失重。
- `Acceleration`：重力加速度，不取决于方向向量的长度。
- `Priority`：多框重叠时的优先级。

选中 `Player`：

- `PlayerController2D`：`Move Speed`（默认 5.5 m/s）、`Jump Speed`（默认 4.6 m/s）、地面/空中加速度、`Body Push Force`（默认 **0.5 N**，身体持续推挤极轻微）。
- `AstronautToolController`：`Field Hold Seconds`（默认 1.5 s）、`Field Disappear Seconds`（默认 3 s，从收起时起算的完全消失时间）。
- `MechanicalArm2D`：`Reach`（默认 2.5 m）、`Push Force`（默认 55 N）、`Grab Spring`（默认 120 N/m）、`Grab Damping`（默认 18 N·s/m）、`Max Grab Force`（默认 90 N）。
- `PlayerHealth`：`Max Health`（默认 100）。
- `PlayerFallDamage2D`：`Safe Fall Height`（默认 3 m）、`Damage Per Meter`（默认 20）。

角色占位 Prefab 在 `Assets/GravityPrototype/Prefabs/Player.prefab`；现有场景的生命与摔落参数请在场景 `Player` 实例上调节。

球的物理参数优先在 `Assets/GravityPrototype/Physics/` 的配置资产中调整：`diameterMeters`、`shellThicknessMeters`、`densityKgPerCubicMeter`、气体/环境空气密度及 `dragCoefficient`；最大运动速度不是手调参数。摩擦/弹性在对应 `*Contact.physicsMaterial2D` 中调整。原 `Assets/GravityPrototype/Art/BallContact.physicsMaterial2D` 保留兼容；地面/墙体现已独立使用 `Physics/GroundContact.physicsMaterial2D`。

现有场景 `Ball` 的 `BallMaterial2D.profile` 默认引用木球。要改变初始球种，请在 Edit Mode 指定另一份 profile，并执行组件菜单 `Apply Material Profile`。

`BallImpactDamage2D`：`Head Region Fraction`（默认 0.35）、`Minimum Head Normal Alignment`（默认 0.55）、`Minimum Incoming Ball Speed`（默认 0.25 m/s，仅方向门控）；`Safe Head Impulse`（默认 5 N·s）、`Impulse Doubling Interval`（默认 10 N·s）、`Exponential Damage Scale`（默认 5 HP）、`Max Damage Per Hit`（默认 100）、`Hit Cooldown`（默认 0.4 s）。`Impact Duration Seconds`（默认 0.10 s）只控制平均力显示。旧线性力伤害字段、速度伤害与旧材质倍率字段隐藏保留兼容，不再用于扣血。

在 Play Mode 里调整的场景值是临时的，停止后会恢复；要保留参数请在 Edit Mode 修改。

人工体验流程：

1. 点击 Play，确认左侧主角持青色装置、默认橙色木球落地；先点击 Game 窗口获取焦点。按 Q/E 和 1/2/3 检查三种装置切换，球种应保持不变。
2. 用 A/D 或方向键移动，轻轻顶住小球；按 2，瞄准距离 2.5 米内的小球，按住左键抓取并移动鼠标，松键释放；按住右键持续推动。隔墙和超距时不应生效，抓取后切装置或失焦应松开。测试空格/W/上键起跳、落地和斜坡行走。
3. 按 1 拖方框分别覆盖小球和主角中心，确认两者都向上加速；主角翻转朝向，方框边缘不挡住任何物体。切到 2 或 3 后不能再拖框，前 1.5 秒保留、随后淡出、3 秒完全消失；再按 1 立即恢复。
4. 持续拖框跟随主角或小球，再移开，确认恢复向下加速且保留已有速度。让框覆盖天花板附近的玩家，确认可以倒立行走并向下跳离支撑面。
5. 让球停稳，再拖框覆盖，确认能重新启动。
6. 在区域边缘和画面边缘拖动，测试点击偏移、出界限制、松键和失焦取消。
7. 按 R 多次，确认主角、小球的位置、速度与方框位置均恢复，且重置不保留跳跃输入、恢复满血。
8. 验证摔落：框外用 Play Mode 中的 Rigidbody2D/Transform 把玩家放到约 6 米高处，下落后观察血条；物理传送调试时需要调用 `PlayerFallDamage2D.ResetTracking()` 清除旧落差。也可拖框将玩家抬高再移开，让实际运动自然记录落差。约 6 米扣约 60 HP，R 恢复为 100。Play Mode 调参不持久化。

9. 验证砸击：让主角站在球下方，将球用重力框抬高后移开框，让其落到角色头上，观察 HP 与简洁的扣血反馈。同样距离分别用木球和铁球测试；R 满血恢复，正常推球应不误伤。

## 尖刺与关卡（PR #3 整合）

- 打开 `Assets/GravityPrototype/Scenes/LevelMenu.unity` 进入选关，或直接打开 `Assets/GravityPrototype/Scenes/PlatformLevel.unity`。
- 已保留 PR 的尖刺（线性/阶梯/延迟伤害）、三座弹射台、终点、计时、最佳成绩存储及选关菜单；脚本统一在 `Assets/GravityPrototype/`，不保留重复的 `Assets/Scripts` / `Assets/Editor` 程序集。
- 弹射台通过 `PlayerController2D.ApplyLaunch` 一次性赋予速度并清空跳跃缓冲，不改变当前重力。接触时弹射、冷却期间不重复弹射；死亡玩家不能触发。
- 弹射台沿用 PR 的右键摆放机制；玩家装备机械臂时，右键优先用于机械臂推动，不同时摆放弹射台。
- 关卡玩家沿用本地的 70 kg、70% 地球重力、相对重力控制和装置系统；不恢复 PR 的旧版 2 kg / 2.4 倍重力玩家。试验场仍使用 R 手动满血复原；平台关卡死亡后按 PR 规则自动重开。
- 尖刺会持续核对实际碰撞重叠，原地复活、清空接触记录或重新启用组件后仍会正确扣血。计时成绩存入 PlayerPrefs；测试使用独立随机记录键并清理。
- 屏幕不显示球材质、质量、摩擦或冲量/平均力；操作提示放在“操作说明”折叠菜单里。
