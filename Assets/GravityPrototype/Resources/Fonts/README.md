# Cubic 11 pixel font

- Upstream: https://github.com/ACh-K/Cubic-11
- Source file: `fonts/ttf/Cubic_11.ttf` on upstream `main`, retrieved 2026-11-04.
- License and original notices: `OFL.txt` alongside the unmodified font. Keep these notices with redistributions.
- Supports Chinese and Latin text. Imported with hinted raster rendering at 24 px (2× the 12 px cell), no synthetic bold. Used by all `PixelUI` labels, buttons, HUD and death messages.
